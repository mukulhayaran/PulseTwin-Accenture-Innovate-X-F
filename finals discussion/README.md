This folder explains the application in the same order as the top navigation.
The wording is intentionally simple and focuses on what a person can see, click, and
decide.

## One-line purpose of each panel

| Panel | Main question it answers |
|---|---|
| Supervisor | What is happening on the line right now, and what needs action first? |
| Manager | Where is production losing output, why, and what change may help? |
| Leadership | Is the system worth the investment, and where should money be spent? |
| Operations | Is PulseTwin itself healthy, current, secure, and using the right model? |
| Copilot | Can I investigate the same information through a verified conversation? |

The landing page also has cards for the four human personas. The top navigation inside
the dashboards adds the Copilot as a fifth tab. The separate Login/Role page is a demo
role picker; it is not a real password-based login.
